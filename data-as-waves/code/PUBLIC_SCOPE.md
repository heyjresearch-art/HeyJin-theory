# PUBLIC_SCOPE.md

## Included

This release contains the implemented analyses required to reproduce the manuscript:
recurrent-period discovery, fixed RF–Pressure relative phase, nested OOF prediction,
cycle-wise relational progression, exploratory progression associations, and Models A/B/C.

## Intentionally not represented as implemented results

- automatic sensor-pair discovery/ranking;
- automatic reference relational structure generation;
- real-time virtual metrology;
- prediction-reliability decision logic;
- feedback/feedforward process control;
- actuator integration.

The boundary is scientific as well as publication-related: these extensions were not
demonstrated by the reported dataset analysis.

## Private master

The preservation baseline is the complete, verified v04 research archive. Public changes
should be made in this repository copy rather than back-propagated into the master unless
they correct a verified research error.
